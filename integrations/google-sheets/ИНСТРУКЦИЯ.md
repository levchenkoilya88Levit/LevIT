# Заявки с сайта → Google Таблица + Telegram

Как это работает: посетитель заполняет форму → заявка становится новой строкой в Google Таблице → вам мгновенно приходит сообщение в Telegram (и, по желанию, письмо на почту).

Займёт ~15 минут. Нужны: Google-аккаунт и Telegram.

---

## Шаг 1. Telegram-бот (2 минуты)

1. В Telegram откройте **@BotFather** → нажмите **Start** → отправьте `/newbot`.
2. Придумайте имя (например, `LevIT Заявки`) и логин бота, заканчивающийся на `bot` (например, `levit_leads_bot`).
3. BotFather пришлёт **ключ (token)** вида `7123456789:AAH...` — скопируйте его.
4. Откройте своего нового бота (ссылка в сообщении BotFather) → нажмите **Start** и напишите ему любое сообщение, например «привет». Без этого бот не сможет вам писать.

> Хотите, чтобы заявки видели несколько человек? Создайте группу в Telegram, добавьте туда бота и напишите в группе любое сообщение.

## Шаг 2. Google Таблица и скрипт (5 минут)

1. Откройте [sheets.new](https://sheets.new) — создастся пустая таблица. Назовите её, например, **«LevIT — Заявки с сайта»**.
2. В меню: **Расширения → Apps Script**.
3. Удалите всё в редакторе и вставьте **целиком** содержимое файла [`Code.gs`](Code.gs).
4. В самом верху, в блоке `CONFIG`, вставьте ключ бота между кавычками:
   ```js
   TELEGRAM_TOKEN: '7123456789:AAH...',
   ```
   Если нужна копия заявок на почту — впишите адрес в `EMAIL`.
5. Нажмите 💾 **Сохранить** (Ctrl+S).

## Шаг 3. Узнать chat id (1 минута)

1. Вверху редактора в выпадающем списке функций выберите **`findMyChatId`** → нажмите **▶ Выполнить**.
2. Google попросит доступ: **Проверить разрешения → ваш аккаунт → Advanced (Дополнительно) → Go to … (unsafe) → Allow (Разрешить)**.
   Предупреждение «приложение не проверено» — нормально: это ваш личный скрипт.
3. Внизу, в **Журнале выполнения**, появится строка `chat id: 123456789 (Ваше имя)`.
4. Вставьте это число в `CONFIG`:
   ```js
   TELEGRAM_CHAT_ID: '123456789',
   ```
   (для группы id начинается с минуса, например `-1001234567890`; несколько получателей — через запятую). Сохраните.

## Шаг 4. Проверка (1 минута)

Выберите функцию **`testLead`** → **▶ Выполнить**.

- В таблице появится лист **«Заявки»** с тестовой строкой.
- В Telegram придёт сообщение «🔔 Новая заявка с сайта».

Тестовую строку потом можно удалить.

## Шаг 5. Опубликовать как веб-приложение (2 минуты)

1. Справа вверху: **Начать развертывание (Deploy) → Новое развертывание (New deployment)**.
2. Шестерёнка ⚙ → **Веб-приложение (Web app)**.
3. Заполните:
   - **Описание:** `Заявки с сайта`
   - **Выполнять как (Execute as):** **Я (Me)**
   - **У кого есть доступ (Who has access):** **Все (Anyone)** ← обязательно, иначе сайт не сможет отправить заявку
4. **Развернуть (Deploy)** → скопируйте **URL веб-приложения**. Он выглядит так:
   `https://script.google.com/macros/s/AKfy…/exec`

## Шаг 6. Подключить к сайту

В файле `_data/company.yml` вставьте ссылку:
```yaml
form_endpoint: "https://script.google.com/macros/s/AKfy…/exec"
```
Или просто пришлите ссылку Claude — он вставит и опубликует.

После публикации сайта (1–2 минуты) оставьте тестовую заявку на levit.com.ua — она должна появиться в таблице и в Telegram.

## Работа с заявками

- Новые заявки появляются **сверху** и подсвечены жёлтым (статус «Новая»).
- Меняйте **Статус** из выпадающего списка: Новая → Связались → В работе → Клиент / Отказ / Спам.
- В колонке **«Комментарий менеджера»** — ваши заметки.
- **«Тип заявки»** и **«Страница»** показывают, откуда пришёл лид: например, «Рішення: Обмін з Rozetka».
- Кнопка «📋 Открыть таблицу заявок» в сообщении Telegram ведёт прямо в таблицу.

## Если что-то изменили в скрипте

После любых изменений в `Code.gs`: **Развертывание → Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть**. Ссылка при этом не меняется.

## Защита от спама

В формах есть скрытое поле-ловушка: боты его заполняют, люди — нет. Такие заявки скрипт молча отбрасывает.
